## 📋 Описание плагина
ChatGuard - плагин для "защиты" вашего чата. Отлавливает сообщение пользователя и проверяет есть ли в сообщении какой-нибудь IP или домен.
Плагин ищет домен или айпи через маску (регулярное выражение), которые вы можете сами отредактировать в конфиге. Есть несколько типов наказания, а также логирование таких сообщений. WhiteList присутствует.

## 👷 Требования
- [Metamod](https://www.sourcemm.net/downloads.php/?branch=master)
- [Utils](https://github.com/Pisex/cs2-menus)

## 🔨 Конфиг
`EnableIP` - 0 - выключить защиту от айпи, 1 - включить защиту от айпи\  
`EnableDomain` - 0 - выключить защиту от доменов, 1 - включить защиту от доменов\ 
`RegularIP` - Сюда можете вписать свою кастомную маску для айпи\ 
`RegularDomain` - Сюда можете вписать свою кастомную маску для доменов\ 
`EnableDomain` - 0 - выключить защиту от доменов, 1 - включить защиту от доменов\ 
`WhiteListIP` - Туда можно ввести список своих IP адресов, обязательно разделяйте пробелом\
`WhiteListDomain` - Туда можно ввести список разрешенных доменов\
`Logs` - 0 - Не логировать сообщения от пользователей, 1 - Логировать сообщения в addons/logs (Имеется ввиду сообщение с содержанием IP адреса)\
`PunishType` - 1 - Выдает предупреждение в чате, 2 - Кикает с сервера, 3 - Кастомная команда\
`CustomCommand` - Туда можно вписать кастомную команду 🦍
